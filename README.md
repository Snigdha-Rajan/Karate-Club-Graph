# Karate-Club-Graph
This repository contains my solution to the DSC 212 assignment, Modularity on the Karate Club Graph, submitted to Prof. Saptarishi Bej, IISER Thiruvananthapuram.
In this project I applied recursive spectral modularity partitioning to Zachary’s Karate Club network to detect communities from the graph structure. I built the adjacency matrix and the modularity matrix B = A − kkᵀ/2m, then split the network using the sign of the leading eigenvector of B, repeating on each group until further split was not possible. After each split, I plotted the graph with colour-coded communities and calculated degree centrality, betweenness centrality, closeness centrality and clustering coefficient for every node within its community and then plotted how these measures changed across iterations.
